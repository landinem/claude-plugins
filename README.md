# Landinem para Claude Code / Landinem for Claude Code

[Español](#español) | [English](#english)

## Español

Tu Claude Code trabaja en Landinem como tu asistente: lee y cambia tus datos, sube ficheros y hace el trabajo que te
encargan los agentes de Landinem, si lo permites. Lo que tiene impacto espera tu aprobación.

Requisito: Node 20 o superior en el `PATH`.

1. Instala el plugin en Claude Code:

   ```
   /plugin install landinem --marketplace landinem/claude-plugins
   ```

2. Responde a las opciones: la URL de Landinem (vacía, `https://landinem.com`) y "Arrancar en remoto".
3. Conecta tu cuenta: `/mcp`, elige `landinem` y pulsa Authenticate.

Los textos del plugin salen en el idioma de tu cuenta de Landinem. `/landinem` pasa la sesión a remoto o a local.
Privacidad: https://landinem.com/privacidad

## English

Your Claude Code works in Landinem as your assistant: it reads and changes your data, uploads files and does the work
Landinem agents assign to you, if you allow it. Anything with impact waits for your approval.

Requirement: Node 20 or later on your `PATH`.

1. Install the plugin in Claude Code:

   ```
   /plugin install landinem --marketplace landinem/claude-plugins
   ```

2. Answer the options: the Landinem URL (empty means `https://landinem.com`) and "Start in remote mode".
3. Connect your account: `/mcp`, choose `landinem` and press Authenticate.

The plugin texts follow the language of your Landinem account. `/landinem` switches the session between remote and
local. Privacy: https://landinem.com/privacidad
